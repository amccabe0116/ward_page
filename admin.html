How the LCR sync works

Attendance taken on this site is pushed into LCR's Class and Quorum Attendance report by a script that runs inside your logged-in LCR tab (it clicks the same buttons you would). The roster is refreshed from that page at the same time.

  1. Open Class and Quorum Attendance in LCR and sign in.
  2. Run scripts/lcr-sync.js in that tab (Claude does this for you on Sunday nights, or on request: “sync attendance to LCR”).
  3. Rows below turn synced once LCR has them.

Only weeks LCR still allows editing can be pushed (LCR opens each week through the coming Sunday).
